# 매장 설계 제안서 (워드)

워드(docx) 스킬로 쓴다. 순서:

1. **표지** — 고객, 제목, 날짜.
2. **설계 콘셉트** — 요청이 바라는 분위기와 재료.
3. **공간 구성 표** — 실 이름 · 면적 · 용도. 앞 단계 평면도의 실별 면적을 그대로 쓴다.
4. **평면도 그림** — 서버가 그림 파일 경로를 주면 넣는다. 쪽 너비에 맞추고(폭 6인치, 높이는 그림 비율대로) 캡션을 단다.
5. **일정** — 요청의 일정이 있으면 그것으로, 없으면 설계 → 공사 → 준공의 일반 순서.
6. **다음 단계** — 고객이 확인할 것.

평면도와 견적서는 다른 단계가 만든다. 다시 만들지 않는다.
