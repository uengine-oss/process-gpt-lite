# 매장 설계 제안서

## 1. 먼저 있어야 하는 것

- 평면도(DXF)와 실별 면적 표(`실 이름 | 면적㎡ | 용도`). 없으면 cadcraft-floor-plan 으로 먼저 만든다.
- 고객 요청 원문(설계 콘셉트·분위기·재료·일정 등 요구사항).

## 2. 아래아한글(hwpx) — 회사 양식 채우기

`references/hwpx-template.md` 를 따른다. 요약:

1. 회사 제안서 양식을 쓴다(양식 주소는 설정에 있다). 양식의 2번 그림 칸('설계 평면도')에 평면도 그림을 넣는다.
2. 표의 행 수는 양식 그대로 두고 칸만 이 고객에 맞게 채운다. '공간 구성' 표는 평면도의 실별 면적으로 채운다.
3. 요청의 요구사항을 빠짐없이 반영한다. 그림 칸은 그대로 둔다.
4. 한글 문서 생성 도구(generate_hwpx)가 있으면 그것으로 채운다. 없으면 양식을 받아 샌드박스에서 채운다.

## 3. 워드(docx) — 영어 고객

`references/docx-outline.md` 의 순서로 쓴다: 표지 → 설계 콘셉트 → 공간 구성 표 → 평면도 그림(쪽 너비에 맞춤, 캡션) → 일정 → 다음 단계. 모든 글은 고객의 언어로 쓴다.

## 4. 결과

파일 이름만 짧게 알린다. 평면도·견적서는 다른 단계가 만들면 다시 만들지 않는다.
