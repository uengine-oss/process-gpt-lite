# 요구사항으로 평면도 그리기 (CADCraft)

## 1. 요구사항 읽기

- 가로·세로 치수(m), 필요한 실(홀·주방·창고·화장실 …), 출입문이 있는 벽, 좌석 수를 요청에서 그대로 읽는다.
- 요청에 없는 값은 지어내지 않는다. 치수가 없으면 배치 규칙의 기본 크기를 쓰고 답에 그렇다고 적는다.

## 2. 배치 정하기

`references/layout.md` 의 배치 규칙을 따른다. 실은 전체 직사각형을 빈틈·겹침 없이 채우고, 가장 큰 실이 홀이다.

## 3. CADCraft 로 그리기

1. 미터 단위 새 도면을 연다.
2. 레이어를 나눈다: 벽(WALL) · 실 구획(ROOM) · 문(DOOR) · 창(WINDOW) · 가구(FURN) · 글자(TEXT) · 치수(DIM).
3. 바깥 벽과 안쪽 벽(두께 0.15 m)을 사각형 두 개로 그린다.
4. 홀이 아닌 실의 구획을 그린다.
5. 출입문(폭 약 1.2 m, 여는 호)과 바깥 벽의 창을 그린다. 창은 문을 가로지르지 않는다.
6. 좌석 수가 있으면 홀에 4인 테이블(원탁 + 의자 4개)을 문이 여는 자리와 실 이름을 피해 줄지어 놓는다.
7. 실마다 이름과 면적(㎡)을 쓰고, 가로·세로 전체 치수를 넣는다.
8. `/workspace/<고객> 평면도.dxf` 로 저장한다.

## 4. 결과

- 실별 면적 표를 `실 이름 | 면적㎡ | 용도` 한 줄씩으로 적는다. 다음 단계(제안서의 공간 구성 표, 견적서의 실별 공사)가 이 표를 그대로 쓴다.
- 도면 크기(가로 × 세로)와 저장한 파일 이름을 짧게 알린다.

## 5. 도구가 없을 때

CADCraft 도구가 목록에 없으면 그리지 않는다. 배치 표(실 이름·위치·크기·면적)만 만들고, 도면은 CADCraft 가 있는 설치에서 그려야 한다고 알린다.
