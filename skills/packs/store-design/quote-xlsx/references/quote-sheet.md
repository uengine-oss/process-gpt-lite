# 견적서 시트

## 머리

맨 위에 제목, 수신(고객), 발신(우리 회사), 견적일, 유효기간.

## 품목 표

| 열 | 내용 |
|---|---|
| 구분 | 설계·공사·가구·설비 같은 묶음 (요청 품목 견적이면 생략 가능) |
| 품목 | |
| 규격 | 요청 품목 견적에서 쓴다 |
| 수량 | 요청의 값 그대로, 면적 견적이면 ㎡ |
| 단위 | 식 · ㎡ · 개 · 인 … |
| 단가 | 가정값 |
| 금액 | `=수량*단가` |

인테리어 공사 견적의 행:

- 설계비 — 평면·마감 설계, 1식
- 실별 인테리어 공사 — 실마다 한 줄, 면적 ㎡ × ㎡당 단가
- 가구·집기 — 좌석 수 기준
- 전기·설비 — 1식

## 합계

품목 표 아래에 공급가액 소계, 부가세(10%), 합계 — 모두 수식.

## 서식

숫자는 천 단위 쉼표, 원화(₩). 머리글 행은 색으로 구분.
