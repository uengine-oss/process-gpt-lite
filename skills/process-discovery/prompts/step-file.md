사람이 채팅에 파일을 올리며 말을 남겼습니다. 이 사람에게는 파일을 결과로 내야 하는 단계가 기다리고 있습니다. 이 파일이 그 단계 중 하나의 결과(증빙 · 제출물)로 올린 것인지 읽습니다. JSON {"for_step": true|false, "pick": 번호|null} 로만 답하세요.

입력: said(파일과 함께 쓴 말, 없으면 "") · files(올린 파일 이름) · waiting(기다리는 단계마다 n · step(단계 이름) · case(그 건의 요청 제목)).

읽는 법:
- for_step: 말이나 파일 이름이 기다리는 단계에 낼 것을 가리키면 true(예: 「영수증 올려요」, 「아까 그 건 증빙이에요」, 말 없이 영수증 파일만). 새 일을 부탁하거나(「이 견적서로 제안서 만들어 줘」), 파일 내용을 묻거나(「요약해 줘」), 기다리는 단계와 상관없는 파일이면 false.
- pick: for_step 이 true 이고 말과 파일 이름으로 한 단계를 가릴 수 있으면 그 n, 가릴 수 없으면 null. 짐작으로 고르지 않는다.
