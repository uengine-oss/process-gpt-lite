## ADDED Requirements

### Requirement: 새 프로젝트는 바로 열린다
시스템은 새 프로젝트 요청에 방을 바로 만들어 답해야 한다(SHALL). 제목을 짓는 모델을 기다리지 않아야 한다(MUST NOT). 처음에는 요청의 첫 줄을 링크를 빼고 짧게 잘라 임시 제목으로 쓰고, 비면 「새 프로젝트」를 쓴다. 모델 제목은 나중에 바꾸고 `thread` 이벤트로 알린다. 그 사이 사람이 이름을 바꿨거나, 모델이 제목 대신 긴 답을 냈거나, 실패했으면 임시 제목을 그대로 둔다. 화면은 방이 만들어지기 전에도 보낸 메시지와 진행 표시를 바로 보여 주어야 한다(SHALL). 방 만들기가 실패하면 보낸 글을 입력창에 돌려주고 알린다.

#### Scenario: 모델이 느리다
- **GIVEN** 제목 모델이 5초 걸린다
- **WHEN** `POST /api/threads` 로 새 프로젝트를 만든다
- **THEN** 1초 안에 방이 돌아오고, 몇 초 뒤 제목이 모델 제목으로 바뀐다

#### Scenario: 보내자마자 보인다
- **GIVEN** 방 만들기 응답이 늦다
- **WHEN** 새 프로젝트 화면에서 글을 보낸다
- **THEN** 1.5초 안에 내 메시지와 「생각하는 중」이 보인다
- **AND** 서버가 저장한 메시지가 와도 같은 메시지가 두 번 보이지 않는다

#### Scenario: 방을 만들지 못했다
- **WHEN** 방 만들기가 실패한다
- **THEN** 보낸 글이 입력창으로 돌아오고, 실패했다는 안내가 보인다

### Requirement: 바로잡는 말로 시작한 사이트 작업은 앞 작업을 대신한다
시스템은 같은 방에서 에이전트 작업이 돌거나 기다리는 동안, 그 요청을 사이트에서 하라는 말이 와서 서버 브라우저 작업이 시작되면, 앞 작업을 멈춰야 한다(SHALL). 멈춘 작업의 답에는 이유를 남겨야 한다(SHALL). 예: 「NotebookLM 에서 하라는 말씀에 따라 앞의 작업은 멈췄어요.」 멈춘 작업은 「완료했습니다」 같은 답을 내지 않아야 한다(MUST NOT). 기다리던 작업은 에이전트 서비스에 보내지 않는다. 앞 작업이 이미 만든 파일은 지우지 않는다.

- 프로젝트 방은 대화가 하나이므로, 같은 방의 새 사이트 작업이 늘 앞 작업을 대신한다.
- 메인 채팅은 여러 일이 나란히 돈다. 그래서 새 말이 80자 이하이고 자기 링크·파일이 없을 때만 「진행 중인 요청을 바로잡는 말인가」를 판정한다. 판정이 0.7 이상인 그 작업 하나만 멈춘다. 판정을 받지 못하면 멈추지 않는다.

링크 없이 NotebookLM 에서 하라는 말에는, 이 방에 사람이 앞서 올린 링크·첨부를 작업의 할 일에 붙여야 한다(SHALL). 프로젝트 방은 최근 사람 메시지 6개, 메인 채팅은 30분 안의 3개를 보고, 각각 최대 5개까지 붙인다.

#### Scenario: 녹화의 순서
- **GIVEN** 규칙이 없는 프로젝트 방에서 유튜브 링크와 「파워포인트·대본·mp3 를 만들어 줘」를 보내 에이전트가 일하는 중이다
- **WHEN** 「노트북엘엠 사이트에 들어가서 생성해야」를 보낸다
- **THEN** 곧 「NotebookLM에서 직접 처리할게요」가 오고, 앞 작업의 답은 멈춘 이유로 끝난다
- **AND** NotebookLM 작업의 할 일에 앞서 올린 유튜브 링크가 들어 있다
- **AND** 그 방에 「완료했습니다」 답이 나오지 않는다

#### Scenario: 메인 채팅의 다른 요청
- **GIVEN** 메인 채팅에서 요약 문서를 만드는 중이다
- **WHEN** 「노트북엘엠에서 내 노트북 목록 보여 줘」처럼 진행 중인 요청을 바로잡는 말이 아닌 요청이 온다
- **THEN** 앞 작업은 멈추지 않고 끝까지 간다

### Requirement: 소리 파일은 그 자리에서 재생된다
시스템은 채팅의 파일 카드가 소리 파일(mp3·m4a·wav·ogg·aac·opus·flac)이면, 카드 아래에 바로 재생되는 플레이어를 보여 주어야 한다(SHALL). 저장소에 올릴 때는 소리·영상 파일에 그 형식(`audio/*`, `video/*`)을 붙여 휴대폰 브라우저가 재생할 수 있게 한다. 주소 없이 작업 공간 경로만 있는 파일은 화면에 뜰 때 주소를 받아 온다. 슬라이드 파일은 지금처럼 누르면 편집기로 열린다.

#### Scenario: 팟캐스트 MP3
- **WHEN** 작업이 만든 mp3 파일 카드가 대화에 올라온다
- **THEN** 카드 아래 플레이어로 바로 들을 수 있다. 구간 요청에 206 으로 답해 넘겨 듣기가 된다
