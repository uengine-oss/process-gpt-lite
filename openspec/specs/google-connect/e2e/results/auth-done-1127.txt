# 로그인 완료 화면은 그 창에서 시작한 로그인만 받는다 (2026-11-27)

## 실행
```bash
cd server && node --test test/urlTokens.test.js test/google-connect.test.js
cd e2e && PGPT_URL=http://localhost:5396 API_URL=http://127.0.0.1:8996 npx playwright test tests/feature/auth-done.spec.js --project feature
```

## 결과
- 단위 BT-A-01~03 3/3: 값은 30분 안에 한 번만 받고 다른 탭의 값은 받지 않는지 확인했다. 이미 로그인한 사람은 다른 사람의 세션이나 시작하지 않은 로그인으로 바뀌지 않는지 확인했다. 설치형 로그인은 `/auth/done?n=<값>#<세션>`으로 돌아오고 화면이 만든 형식이 아닌 값은 싣지 않는지 확인했다.
- e2e F-AD-01~04 4/4(Chrome): 세션이 붙은 `/auth/done` 링크(값 없음 · 다른 값 · Supabase 꼴 fragment · 오류 문구)로는 로그인되지 않는지 확인했다. 로그인 화면에 「이 창에서 시작한 로그인만 완료할 수 있어요. 다시 로그인해 주세요.」가 보이고 링크의 문구는 보이지 않는지 확인했다. 설치형 「Google로 계속하기」는 그 창이 보낸 값으로 돌아와 로그인되고 같은 주소를 다시 열어도 바뀌지 않는지 확인했다. 게이트웨이 로그인은 `redirect_to`가 `<주소>/auth/done?n=<48자>`이고 돌아오면 로그인되는지 확인했다. 이미 로그인한 사람은 다른 사람의 세션으로 바뀌지 않는지 확인했다.
- 이 시험에서는 시험 브라우저가 해당 단계를 흉내 내도록 했다. 실제 Google과 로그인 서버에는 가지 않았다.
