# 휴대폰에서 문서 편집기 보기

## Purpose
이 스펙은 휴대폰이나 좁은 화면에서 이음오피스 편집기를 열 때의 배치를 정한다. 편집기 이미지는 그대로 두고 Lite 쪽에서 바꾼다. 근거는 2026-11-21 휴대폰 녹화(결정 D-1121-11)다.

## Requirements

### Requirement: 휴대폰에서 접힌 리본은 탭 줄도 숨긴다
시스템은 휴대폰이나 좁은 화면(편집기 칸 폭 640px 이하, 또는 터치 위주 기기)에서 리본을 접으면, 편집기의 탭 줄(파일·저장·되돌리기·자동 저장·홈·삽입 …)까지 숨겨야 한다(SHALL). 그만큼 문서 영역이 넓어진다. 상단의 「리본 펴기」를 누르면 탭 줄과 리본이 함께 돌아와야 한다(SHALL). 편집기 안에서 리본을 접거나 펴도, 상단의 단추가 그 상태를 따라야 한다. 펼친 탭 이름은 글자 단위로 쪼개지지 않아야 하고, 줄이 넘치면 아래 줄로 이어진다. 넓은 화면의 동작은 바뀌지 않는다.

#### Scenario: 휴대폰 세로로 연다
- **WHEN** 390×844 화면에서 채팅의 PPT 파일 카드를 누른다
- **THEN** 편집기에 탭 줄이 보이지 않는다
- **AND** 「리본 펴기」를 누르면 파일·홈·삽입 … 탭의 글자가 한 줄로 보이고, 다시 접으면 사라진다

#### Scenario: 넓은 화면
- **WHEN** 1440×900 화면에서 리본을 접는다
- **THEN** 탭 줄, 썸네일 줄, 노트가 전처럼 남는다

### Requirement: 휴대폰에서 슬라이드는 화면 폭에 맞춰 넘겨 본다
시스템은 휴대폰에서 PPT를 열 때 슬라이드 썸네일 줄을 접고, 슬라이드를 편집기 영역 폭에 맞춰 보여 주어야 한다(SHALL). 슬라이드 양옆에는 이전·다음 단추를 둔다. 상단의 「슬라이드 목록」으로 썸네일 줄을 다시 펼 수 있다. 화면 높이가 낮으면(가로) 노트를 숨겨 슬라이드가 화면 높이에 맞게 보이도록 하고, 다시 세로가 되면 되돌린다. 편집기 이미지는 바꾸지 않는다. 편집기의 기존 기능(썸네일, 노트 단추, 맞춤 확대)으로 동작한다.

#### Scenario: 넘겨 본다
- **WHEN** 휴대폰 세로에서 6장짜리 PPT를 열고 다음 단추를 누른다
- **THEN** 썸네일 줄 없이 1장이 폭에 맞게 보이다가 2장으로 넘어간다. 상태 줄에 「슬라이드 2/6」이 보인다

#### Scenario: 가로로 돌린다
- **WHEN** 844×390 화면에서 PPT를 연다
- **THEN** 탭 줄이 없고 노트가 숨겨져, 슬라이드가 화면 높이에 맞는다

#### Scenario: 다른 문서
- **WHEN** 휴대폰에서 워드·엑셀 문서를 연다
- **THEN** 접힌 리본은 탭 줄 없이 열리고, 그 밖의 배치는 깨지지 않는다

### Requirement: 휴대폰에서 엑셀 표는 손가락으로 끌면 스크롤된다
시스템은 터치 화면에서 엑셀 문서를 열 때, 표 위에서 손가락 하나로 끌면 칸을 선택하지 않고 손가락이 움직인 만큼 표를 위아래·좌우로 스크롤해야 한다(SHALL). 빠르게 튕기면 조금 더 미끄러지다가 멈추고, 손가락을 멈췄다가 떼면 그 자리에 멈춘다. 한 번 탭하면 해당 칸을 선택하고, 두 번 탭하면 해당 칸을 편집하며, 길게 누른 뒤 끌면 범위를 선택해야 한다(SHALL). 보기 전용 모드와 편집 모드에서 모두 동일하게 동작한다. 마우스와 펜, 표 밖(수식 입력줄·칸 편집기·메뉴)에서의 터치 동작은 기존과 같다. 편집기 이미지는 바꾸지 않는다. 근거는 2026-11-26 사용자 질문(「엑셀 이음오피스를 모바일에서 열었을때 쓰기모드라서 스크롤 할 수 없는문제」)이다. 이전에는 손가락으로 끌면 범위가 선택되고 표는 움직이지 않았다.

#### Scenario: 끌어서 내려 본다
- **WHEN** 390×844 터치 화면에서 200행짜리 엑셀 문서를 열고, 표를 손가락으로 아래에서 위로 끈다
- **THEN** 선택한 칸은 그대로 유지되고(범위가 선택되지 않음) 표는 아래쪽 행으로 스크롤된다
- **AND** 화면의 같은 위치를 탭하면 처음보다 아래쪽 행의 칸이 선택된다

#### Scenario: 옆으로 끈다
- **WHEN** 표를 오른쪽에서 왼쪽으로 끈다
- **THEN** 오른쪽 열이 보이고, 탭하면 다른 열의 칸이 선택된다

#### Scenario: 길게 눌러 범위를 고른다
- **WHEN** 칸을 잠시 누르고 있다가 그대로 끈다
- **THEN** 표는 스크롤되지 않고 누른 칸부터 손가락이 멈춘 칸까지 범위가 선택된다

#### Scenario: 두 번 탭해 고친다
- **WHEN** 칸을 빠르게 두 번 탭한다
- **THEN** 해당 칸의 편집기가 열린다
