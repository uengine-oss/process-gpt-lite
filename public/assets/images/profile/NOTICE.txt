Preset profile pictures (1.jpg … 8.jpg, user-1.jpg … user-10.jpg)

These are the 18 preset pictures of Process GPT's account settings
(github.com/uengine-oss/process-gpt-vue3, public/assets/images/profile/), copied byte for byte so that
Process GPT Lite shows the same pictures when it is installed without Process GPT in front of it.
Users' saved choice is the root path (/assets/images/profile/<name>), as Process GPT saves it.

Process GPT took them from WrapPixel's "Spike Free Vue Js Admin Template"
(github.com/wrappixel/spike-vue-free: package/public/assets/images/users/1-8.jpg and
package/src/assets/images/profile/user-1..10.jpg — the same git blob hashes), which WrapPixel publishes
